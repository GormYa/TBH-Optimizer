Gold per jam

Mengukur gold asli tiap run dan memproyeksikan penghasilan per jam — kotor dan terkoreksi.

XP per jam

Melacak XP tiap hero dan memperkirakan map terbaik untuk naik level.

Chest & loot

Peluang chest per stage dan tabel loot item per item, lengkap dengan rarity dan sprite.

Pilih fokus (gold atau xp) dan aplikasi menunjukkan stage terbaik dari semuanya.

Cara pakai

Unduh dan buka

Jalankan optimizer.exe. Tidak perlu instal apa pun.

Dasbor terbuka sendiri

Terbuka di browser pada localhost:8080 dan mulai memantau save kamu.

Main seperti biasa

Setiap stage yang selesai memperbarui statistik. Kalibrasikan 1-1 untuk proyeksi yang lebih akurat.

Karena aplikasi tidak ditandatangani, Windows SmartScreen bisa menampilkan peringatan "penerbit tidak dikenal". Itu wajar: klik Info selengkapnya → Tetap jalankan. Kodenya open source — cek di repositori GitHub.

Perguntas Frequentes (FAQ)
O que é o Taskbar Hero Optimizer? +

O Taskbar Hero Optimizer (TBH Optimizer) é uma ferramenta gratuita de código aberto feita para otimizar o ganho de Ouro (Gold), Experiência (XP) e Gerenciamento de Baús no jogo ocioso Taskbar Hero. Ele analisa o arquivo de salvamento do jogo em tempo real para calcular estatísticas exatas de eficiência por fase.

Como encontrar o arquivo de save (SaveFile_Live.es3) do jogo? +

O arquivo de save padrão do jogo é monitorado automaticamente pelo aplicativo no Windows. Ele fica localizado na pasta %USERPROFILE%\AppData\LocalLow\TesseractStudio\TaskbarHero\SaveFile_Live.es3. O aplicativo lê este arquivo a cada atualização em tempo real, sem modificar seus dados.

Como funciona o Cooldown e o Tracker de Baús? +

Os baús de Taskbar Hero são itens do Steam Inventory Service e possuem cooldowns validados no servidor da Steam. O monitor lê esses dados diretamente do cache do Steam local (inventorymsgcache). Os baús normais (cinza) possuem cooldown de 11 minutos (limite de 3 drops por 33 min), enquanto os baús de chefe de fase (azuis) possuem cooldown de 9 minutos (limite de 3 drops por 27 min).

O acúmulo de baús comuns melhora o drop de baús de boss? +

Sim! Deixar o inventário de baús comuns cheio impede que o jogo envie requisições de drops comuns para os servidores da Steam. Isso evita que você gaste o seu Limite Diário de Drops da Steam (Daily Drop Limit) com baús de menor valor, permitindo que todas as suas requisições diárias de drop sejam direcionadas exclusivamente para os valiosos baús de boss (azuis).

A ferramenta é segura? Pode causar banimento? +

Sim, é 100% segura. O otimizador opera estritamente de forma somente leitura (read-only), analisando o save e o cache local sem alterar a memória do jogo, sem injetar código e sem alterar arquivos de salvamento. O código-fonte é totalmente aberto e auditável no GitHub.
